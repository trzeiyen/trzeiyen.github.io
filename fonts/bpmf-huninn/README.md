# 注音粉圓（BpmfHuninn）網頁字型

來源：ButTaiwan/bpmfvs v1.500（https://github.com/ButTaiwan/bpmfvs），由 TTF 轉為 WOFF2，未修改字形。授權見同資料夾 LICENSE 檔。

使用方式：

```css
@font-face{font-family:"BpmfHuninn";src:url("https://trzeiyen.github.io/fonts/bpmf-huninn.woff2") format("woff2");font-display:swap}
body{font-family:"BpmfHuninn",sans-serif}
```

注意：多音字只顯示預設讀音（例如「銀行」的「行」），上課前請檢查。
